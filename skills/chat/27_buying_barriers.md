# 27 · Rank the buying barriers

**A synthesis step.** You don't read comments here — you read the outputs of the
extraction skills and turn scattered findings into one ranked stack.

Attach: objections (18), and where you have them, limiting beliefs (13), failed
solutions (14) and buying criteria (17).

## The job

Everything blocking a purchase, resolved into one ordered list, split in two:

```
PRIMARY     the sale does not happen until this is answered
SECONDARY   costs conversions and adds friction, but a motivated buyer gets past it
```

That distinction is the whole deliverable. It's a build order — what your page has
to answer above the fold versus what belongs in an FAQ.

## Merge across dimensions

The same barrier shows up wearing four different costumes:

```
14 failed solution   "the last two pillows went flat in a month"
18 objection         "I don't believe it'll still be supportive in six months"
13 limiting belief   "they all go flat eventually, it's not worth it"
17 criterion         "must not lose loft"
```

That is **one barrier** — durability scepticism — seen from four angles. Merge it,
and record all four source dimensions, because each one tells you something
different about how to answer it.

## Rank on three things

```
how many people show it
how completely it blocks the sale
how answerable it is with something you could actually produce
```

An unanswerable barrier is still a primary barrier — say so plainly. "This segment
doesn't believe the category works" is worth knowing even when the answer is
"choose a different segment."

## Give me

The ranked stack, primary first. For each: the barrier in one line, how many people,
which dimensions it came from, the customer's own phrasing, and what would answer it.

Then the one-line version: **the three things that have to be true on the page
before anyone in this segment buys.**
