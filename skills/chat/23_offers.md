# 23 · Offers

The deal structures people mention or react to — and which ones move them.

## What one is

A value structure plus a reaction:

```
discounts · bundles · guarantees · free trials · subscriptions · financing
bonuses · delivery and returns terms
```

## The reaction is the finding

"Free returns" mentioned is nothing. "Free returns" as the reason someone finally
risked a purchase is everything.

```
❌ "they do 20% off sometimes"          ✅ only bought once there was a 100-night trial
                                            — "no way I'm buying a pillow I can't return"
```

## Watch for offers that repel

Discounts can read as desperation in a category where people have been burned. A
subscription can be a dealbreaker for someone who's already spent too much on this
problem. Record negative reactions with the same care as positive ones — they're
rarer and more useful.

## Give me

Each offer type, how many mention it, whether the reaction is positive, negative or
conditional, and the exact wording. Then a short list of which offer structures
this segment appears to actually need — usually tied straight back to their
objections (18) and desired proof (20).
